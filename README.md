# no-clue-source-code
Source code for no clue, by Nano Productions.
This is to create mods for the game, and MUST credit Nano Productions.
Using the source code is the exported, Windows version of the game, while other files (such as app.asar) contain the files to the game.
You may use an online editor ( like https://www.ezyzip.com/open-extract-asar-file.html ), but there will also be a "Files.zip" for the files.

! IMPORTANT !
IF YOU DO NOT CREDIT NANO PRODUCTIONS FOR THE ORIGINAL GAME, YOUR MOD WILL BE TAKEN DOWN IF YOU DO NOT CREDIT!
